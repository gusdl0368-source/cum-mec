# V26 템플릿 캡처 도구

LDPlayer(또는 다른 안드로이드 에뮬레이터)에 ADB로 연결해서 V26 화면을 캡처하고,
마우스 드래그 한 번으로 템플릿 PNG로 저장합니다. 이렇게 만든 이미지는 자동으로
`app/src/main/assets/templates/<일과>/<이름>.png`에 저장돼서 매크로 APK가 바로
사용합니다.

## 빠른 시작 (Windows)

1. **LDPlayer를 켜고 V26을 실행** 합니다.
2. 이 폴더의 **`start.bat`** 을 더블클릭합니다.
   - Python이 없으면 설치 안내가 나옵니다.
   - 처음 한 번만 Pillow 패키지를 자동 설치합니다.
3. 도구가 LDPlayer를 자동으로 탐지(`127.0.0.1:5555`부터 16개 포트 스캔)합니다.
4. 좌측 트리에서 캡처할 템플릿을 선택 → 우측 화면에서 **드래그로 영역 선택** → **저장**.

## 사용 화면

```
┌──────────────────────────────────────────────────────────────┐
│ 에뮬레이터: 127.0.0.1:5555 (1280x720)  [다시 탐지][새로고침] │
├───────────────┬──────────────────────────────────────────────┤
│ 필요한 템플릿 │            (LDPlayer 화면 미리보기)          │
│  ★ entry  필수│                                              │
│  ★ claim  ✓   │      ← 마우스로 드래그해서 영역 지정         │
│  · empty      │                                              │
│  ...          │                                              │
├───────────────┼──────────────────────────────────────────────┤
│               │ 버킷: sponsor  이름: claim                   │
│               │ 선택: (320,180) 220x80      [선택초기화][저장]│
└───────────────┴──────────────────────────────────────────────┘
```

- ★ = 필수 템플릿, · = 선택 템플릿
- ✓ = 이미 PNG가 저장돼 있음

## PNG 저장 vs 좌표 저장

같은 항목에 두 가지 방식으로 저장할 수 있고, **둘 다 있으면 좌표가 우선**합니다:

| 방식 | 동작 | 추천 상황 |
|------|------|-----------|
| **PNG로 저장** | 드래그 영역을 잘라 `assets/templates/<버킷>/<이름>.png` 로 저장. 매크로가 OpenCV 템플릿 매칭으로 그 화면을 찾을 때 사용 | 화면 상태 식별 (예: `confirm`, `retry`, `result`), 위치가 변하는 버튼, 색이 바뀌지 않는 버튼 |
| **좌표로 저장** | 드래그 영역의 **중심점**을 정규화 좌표(0~1)로 `assets/coords.json` 에 저장. 매크로가 그 위치를 탭 | 메뉴 진입 버튼처럼 **항상 같은 위치에 있고 팀 컬러로 배경이 바뀌는** 항목 |

좌표가 정의된 항목은 트리에 **📍** 표시가 뜹니다.

### 좌표 가드 (조건부 좌표 탭)

좌표를 그냥 누르면 다른 화면에서 잘못 탭할 위험이 있어요. **"좌표 가드"** 콤보에서
PNG 템플릿을 하나 선택하면 그 PNG가 화면에 보일 때만 좌표를 탭합니다 — 안 보이면
실패. 예:

| 항목 | 좌표 | 가드 |
|------|------|------|
| `pointshop/entry` (메인의 상점 버튼) | (0.5, 0.85) | `home/playball` |
| `specialmatch/entry` (플레이볼 안의 스페셜매치 탭) | (0.4, 0.5) | `homerunrace/entry` |

→ "메인 화면(플레이볼이 보임)일 때만 상점 위치 탭", "플레이볼 메뉴(홈런레이스 탭이 보임)일 때만 스페셜매치 위치 탭".

**가드는 선택사항**입니다. 가드 없이 저장하면 화면 상태와 무관하게 그냥 탭합니다.

## 단축키

- `F5` — 화면 새로고침
- `Ctrl+S` — PNG로 저장
- `Ctrl+D` — 좌표로 저장

## 캡처 팁

- **너무 크게 자르지 마세요.** 버튼 글자/아이콘만 들어가도록 60×40 ~ 200×80 정도로 자르면 됩니다.
- **애니메이션이 있는 영역은 피하세요** (반짝이는 별, 카운트 숫자 등).
- 같은 메뉴를 두 번 캡처할 때는 **에뮬레이터 해상도를 고정**해두세요.
- LDPlayer 해상도는 **설정 → 디스플레이 설정** 에서 1280×720 또는 1920×1080 권장.

## ADB 연결이 안 될 때

도구는 다음 순서로 ADB 실행 파일을 찾습니다:
1. 시스템 PATH의 `adb.exe`
2. `C:\LDPlayer\LDPlayer9\adb.exe` 등 LDPlayer 기본 설치 경로
3. 환경변수 `LDPlayer` / `LDPLAYER`

LDPlayer ADB가 안 켜진 경우:
- LDPlayer 메인 화면 → **설정 → ADB 설정 → "로컬 연결 켜기"**
- 또는 LDPlayer 9의 경우 기본적으로 켜져 있음 — 다시 시작해보세요

수동 확인:
```cmd
"C:\LDPlayer\LDPlayer9\adb.exe" connect 127.0.0.1:5555
"C:\LDPlayer\LDPlayer9\adb.exe" devices
```

```
├── manifest.py            ← 어떤 템플릿이 필요한지 목록
├── requirements.txt       ← Pillow
└── README.md              ← 이 파일
```
